Status: pending implementation and live verification, updated22 October 2026. These are manual acceptance scenarios, not automated tests added or executed. Static source review, compilation, successful migration and physical walkthrough are separate evidence and must be recorded separately. Use fictional family data; do not inspect or import private journal contents.
